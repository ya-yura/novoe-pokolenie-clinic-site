# Новое поколение — сайт медицинского центра

Автономная концепция нового сайта медицинского центра «Новое поколение» в Краснодаре: мобильная посадочная страница, понятный маршрут пациента, направления, специалисты, FAQ, контакты и быстрые CTA для звонка, WhatsApp и заявки.

## Запуск

Требуется Node.js `>=22.13.0`.

```bash
npm install
npm run dev
```

Проверка перед публикацией:

```bash
npm run lint
npm test
```

## Что внутри

- `app/page.tsx` — весь контент и интерактивы главной страницы;
- `app/globals.css` — адаптивная визуальная система;
- `public/images/` — локальные изображения, собранные с официального сайта;
- `research-notes.md` — факты и ссылки на источники;
- `commercial-offer.md` — коммерческое предложение на 50 000 ₽;
- `outreach-message.md` — готовое письмо и контакты для отправки;
- `.github/workflows/deploy-pages.yml` — автоматическая публикация статической версии на GitHub Pages.

## Важно для передачи в работу

Форма на демо-версии показывает полный пользовательский сценарий и подтверждение заявки, но не отправляет данные в CRM или почту. Перед запуском в продакшн нужно подключить фактический канал обработки заявок, проверить юридические тексты и согласовать расписание, цены и состав услуг с клиникой.

## Материалы

Сайт собран по открытым материалам официального сайта, карточек 2ГИС, Яндекс и НаПоправку. Медицинские утверждения и коммерческие условия требуют финальной проверки со стороны клиники перед публикацией.
